IoT Smart Trash Bin System based on ESP32
Project Status: Completed | Role: Hardware & IoT Engineer

📖 Project Overview
This project is an automated waste management system designed to improve hygiene and efficiency. It features a touchless lid mechanism using ultrasonic sensors and real-time "Full Capacity" notifications sent to a smartphone via Telegram Bot.

🛠 Tech Stack
Microcontroller: ESP32 DEVKITC V4

Sensors: HC-SR04 (Ultrasonic), TCRT5000 (Infrared)

Actuator: Servo MG996R

Power: Li-ion 18650 Batteries + TP4056 Module

Connectivity: Wi-Fi & Telegram Bot API
